# TreeForge documentation

TreeForge converts directory structures and AI-generated text trees into diagrams.

## User guides

- [Getting started](getting-started.md): installation, CLI and Python API.
- [Layouts and outputs](rendering.md): vertical/horizontal SVG, Mermaid, Graphviz and TXT.
- [Configuration](configuration.md): depth, grouping, file categories, colors and themes.
- [File types](file-types.md): Office, JSON, ZIP, TXT and other default icons.
- [Icons](icons.md): built-in symbols and custom SVG packs.
- [Examples](examples/README.md): four preview images generated from one structure.
