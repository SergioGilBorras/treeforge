# Changelog

## 0.1.0

- Native vertical and horizontal SVG tree diagrams, with optional slim node boxes.
- Directory, text tree and file path inputs with depth and grouping configuration.
- File-type icons for Office documents, structured data, archives, audio and video.
- Support for custom SVG icon directories.
- Text, Mermaid and Graphviz exports.
- Optional safe YAML configuration.
- Project documentation website and generated example gallery.

Further changes will be recorded by release version.
