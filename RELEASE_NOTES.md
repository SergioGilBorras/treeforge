# TreeForge v0.1.0

First public version of TreeForge, a Python library and command-line tool for clear, customizable directory-structure diagrams.

## Features

- Native SVG rendering in vertical and horizontal orientations, with optional slim node boxes.
- Default file-type icons for folders, source code, Office files, structured data, archives, images, audio and video.
- Optional custom SVG icons with `--icons-dir`.
- Directory scanning, path-list and AI-generated text-tree input.
- Grouping and simplification controls, light/dark themes and custom colors.
- SVG, TXT, Mermaid and Graphviz-based output; optional YAML configuration.

## Installation

Install this exact version directly from GitHub:

```bash
python -m pip install git+https://github.com/SergioGilBorras/treeforge.git@v0.1.0
```

Or download the wheel or source archive attached to this release.
